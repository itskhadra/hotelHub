# HotelHub

HotelHub is a hotel booking website built using React and Firebase.

## Live Website

https://hotelhub-d01cf.web.app
- **Figma Wireframe:** https://www.figma.com/design/b1jGWrxYQiHhyHZymhOJ4f/HotelHub-Website-Wireframe.?node-id=0-1
  presentation link https://drive.google.com/file/d/12Vc5ZikRTTlC9c_4UbrQjxY6uqD4Gbm1/view?usp=sharing

## Features

- View hotel rooms and facilities.
- Register and log in.
- Create hotel bookings.
- View, edit, and delete bookings.
- Store booking information in Cloud Firestore.

## Technologies Used

- React
- JavaScript
- Firebase Authentication
- Cloud Firestore
- CSS
- Vite

## Run Locally

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
