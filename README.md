# HotelHub

HotelHub is a hotel booking website built using React and Firebase.

## Live Website

https://hotelhub-d01cf.web.app

## Features

- View hotel rooms and facilities.
- Register and log in.
- Create hotel bookings.
- View, edit, and delete bookings.
- Store booking information in Cloud Firestore.

## Technologies Used

- React
- JavaScript
- Firebase Authentication
- Cloud Firestore
- CSS
- Vite

## Run Locally

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
